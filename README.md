## 🚢 How to Deploy to Vercel

Since this project uses pure static HTML, CSS, and Vanilla JavaScript with no build steps or heavy packages, it deploys to Vercel in seconds!

### Option 1: Deploy with Git (Easiest & Recommended)

1. Initialize git and commit:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Cyberdeck Terminal"
   ```
2. Push the repository to your GitHub account:
   ```bash
   git remote add origin https://github.com/your-username/fake-random-code-terminal.git
   git branch -M main
   git push -u origin main
   ```
3. Go to [vercel.com](https://vercel.com) and log in.
4. Click **"Add New..."** -> **"Project"**.
5. Import your `fake-random-code-terminal` repository.
6. Click **"Deploy"** (keep all default framework preset options as "Other").
7. Your terminal is live! 🎉

### Option 2: Deploy with Vercel CLI

1. Install the Vercel CLI (if not already installed):
   ```bash
   npm i -g vercel
   ```
2. In this project folder, run:
   ```bash
   vercel
   ```
3. Follow the prompts and your site will be deployed instantly. To publish directly to production:
   ```bash
   vercel --prod
   ```
